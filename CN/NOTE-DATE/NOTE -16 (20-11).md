- when PC0 ping the other device within the network or different network 
- ICMP protocol belongs to network layer 
- network layer contains Ip packet that Ip packet contains SRC and DST Ip address and ICMP in payload
- data link layer contains a protocol called as Ethernet 
- ethernet contains MAC SRC and DST 
- it Checks ARP cache if the mac address is founds in ARP Cache it is okay otherwise we performs ARP operation  
- and stores that DST Mac address at ARP cache finally ethernet access from it
