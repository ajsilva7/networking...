### Purpose of the OSI Model

- Standardizes network communication.
- Breaks communication into 7 layers.
- Makes troubleshooting easier.
- Ensures interoperability between different vendors.
- Simplifies network design and learning.


## 7 Layers of the OSI Model (Top → Bottom)

| Layer | Name         | PDU     | Main Function                                                 |
| ----- | ------------ | ------- | ------------------------------------------------------------- |
| 7     | Application  | Data    | Provides network services to users/applications               |
| 6     | Presentation | Data    | Encryption, decryption, compression, encoding                 |
| 5     | Session      | Data    | Establishes, manages, and terminates sessions                 |
| 4     | Transport    | Segment | End-to-end communication, reliability, flow control (TCP/UDP) |
| 3     | Network      | Packet  | Routing, logical addressing (IP), path selection              |
| 2     | Data Link    | Frame   | MAC addressing, framing, error detection, switching           |
| 1     | Physical     | Bits    | Transmits bits through cables or wireless media               |

## Devices at Each Layer

- **Layer 3 (Network):** Router
- **layer 7 (Application):** computer, server
- **Layer 2 (Data Link):** Switch, Bridge
- **Layer 1 (Physical):** Hub, Repeater, Cables
