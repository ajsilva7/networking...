## 1. Application Layer (L7–L5)

```
DATA
```

- The application (WhatsApp, Chrome, YouTube, etc.) creates the data.
- At this point, it's just called **Data**.

---

## 2. Transport Layer (Layer 4)

```
TCP Header | DATA
```

This forms a **Segment**.

The TCP header contains information like:

- Source Port
- Destination Port
- Sequence Number
- Acknowledgment Number
- Flags (SYN, ACK, FIN, etc.)
- Window Size

Now the data is called a **TCP Segment**.

---

## 3. Network Layer (Layer 3)

```
IP Header | TCP Header | DATA
```

This forms a **Packet**.

The IP header includes:

- Source IP
- Destination IP
- TTL
- Protocol (TCP or UDP)
- Header checksum

Notice that the TCP segment becomes the payload of the IP packet.

---

## 4. Data Link Layer (Layer 2)

```
MAC Header | IP Header | TCP Header | DATA | FCS
```

This forms a **Frame**.

The frame contains:

- Destination MAC Address
- Source MAC Address
- EtherType
- Payload (IP Packet)
- FCS (Frame Check Sequence)

The IP packet becomes the payload of the Ethernet frame.

---

## 5. Physical Layer (Layer 1)

```
101100101010...
```

The entire frame is converted into bits and transmitted through:

- Copper cable
- Fiber optic cable
- Radio waves (Wi-Fi)

## Troubleshooting

**Finding the root cause of a problem and fixing it using a logical process. It is not guessing**.


1. Define the Problem
        ↓
2. Gather Information
        ↓
3. Determine the Scope
        ↓
4. Form a Hypothesis
        ↓
5. Test the Hypothesis
        ↓
6. Identify the Root Cause
        ↓
7. Fix the Problem
        ↓
8. Verify the Solution
        ↓
9. Document the Issue


# Example: "YouTube is buffering"

### Step 1

Problem:

YouTube buffers every few seconds.
### Step 2

Gather information.

- Other websites?
- Other devices?
- Speed test?
- Wi-Fi signal?
- Ethernet?
### Step 3

Scope

- Only my laptop?
- Everyone?
### Step 4

Possible causes

- Weak Wi-Fi
- ISP slow
- DNS
- High CPU
- Router overload
### Step 5

Test

- Try Ethernet.
- Test another device.
- Ping the router.
- Ping 8.8.8.8.
- Run a speed test.
### Step 6

Root cause

Weak Wi-Fi signal.
### Step 7

Move closer to the router.
### Step 8

YouTube now streams normally.
### Step 9

Document:

Weak Wi-Fi due to distance.
