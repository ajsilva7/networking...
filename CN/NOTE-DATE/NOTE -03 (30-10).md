### Class C

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120104742.png)

Here you can see a **Class C IPv4 address**. In the traditional classful addressing system, a Class C address uses the **first three octets as the Network ID** and the **last octet as the Host ID**.

The host portion ranges from **0 to 255**, giving **256 possible values (2⁸ = 256)** because one octet contains 8 bits.

However, **not all 256 addresses can be assigned to hosts**:

- **192.168.1.0** → **Network Address** (identifies the network)
- **192.168.1.1 – 192.168.1.254** → **Usable Host Addresses**
- **192.168.1.255** → **Broadcast Address** (used to send data to all devices in the network)

Therefore, in a **/24 network**, there are **256 total addresses**, but only **254 usable host addresses**.

**Why are there only 254 usable IP addresses instead of 256?**

Because **192.168.1.0** is reserved as the **network address**, and **192.168.1.255** is reserved as the **broadcast address**. Therefore, only **192.168.1.1 to 192.168.1.254** can be assigned to devices.

### Class B Range

- **IP Range:** `128.0.0.0 – 191.255.255.255`
- **Private Range:** `172.16.0.0 – 172.31.255.255`

Class B IPv4 addresses use the first two octets as the Network ID and the last two octets as the Host ID. The host portion is 16 bits long, giving 2¹⁶ or 65,536 possible host combinations. Host addresses increase from 172.16.0.0 to 172.16.0.255, then continue with 172.16.1.0, 172.16.1.1, and so on until 172.16.255.255. In the traditional classful model, devices are on the same network if the first two octets match

## Subnet Mask

A subnet mask is a 32-bit number that separates an IP address into the Network ID and the Host ID. It helps a device determine whether the destination is on the same network or a different network.

A subnet mask is used to identify the network and host portions of an IP address

## Reserved IPv4 Addresses

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120105006.png)

### 1. Loopback Address

127.0.0.1 is the loopback address used to test the local computer's network stack without using the physical network.
### 2. Network ID

The Network ID identifies the network. It is the first address in a subnet and cannot be assigned to a device.*

Example:

```
192.168.1.0/24
```

### 3. Broadcast ID
 
 The Broadcast ID is the last address in a subnet and is used to send data to every device on that network.

Example:

```
192.168.1.255/24
```

### 4. Class D

 Class D addresses (224.0.0.0–239.255.255.255) are used for multicast communication.

### 5. Class E

Class E addresses (240.0.0.0–255.255.255.255) are reserved for research and experimental purposes.

### 6. APIPA

APIPA (169.254.x.x) is an Automatic Private IP Address assigned when a DHCP server is unavailable.
