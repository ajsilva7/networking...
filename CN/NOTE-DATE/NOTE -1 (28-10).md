# 1. What is a MAC Address?

**Definition:**

 A MAC address is a unique physical (hardware) address assigned to a network interface card (NIC). It is used to identify a device within a local network.

- **OSI Layer:** Layer 2 (Data Link)
- **Example:** `00:1A:2B:3C:4D:5E`

---

# 2. What is an IP Address?

**Definition:**

 An IP address is a logical address used to identify a device and communicate across different networks.

- **OSI Layer:** Layer 3 (Network)
- **Example:** `192.168.1.10`

---

# 3. What is a Port Number?

**Definition:**

 A port number is a logical endpoint that identifies a specific application or service running on a device.

- **OSI Layer:** Layer 4 (Transport)
- **Examples:**
- HTTP → 80
- HTTPS → 443
- SSH → 22
- RDP → 3389
- SMB → 445

**What is a protocol?**

A protocol is a set of rules that defines how devices communicate and exchange data over a network. It ensures that both devices use the same standards so they can understand each other and communicate successfully.


**What is an IPv4 address?**

An IPv4 address is a 32-bit logical address used to uniquely identify a device on a network. It consists of four octets, and each octet contains 8 bits. Every octet can have values from 0 to 255 because 2⁸ equals 256 possible values. IPv4 addresses are written in dotted decimal notation, such as 192.168.1.10.

# IPv4 vs IPv6 

|Feature|IPv4|IPv6|
|---|---|---|
|Full Form|Internet Protocol Version 4|Internet Protocol Version 6|
|Introduced|1981|1998 (RFC 2460), widely deployed after 1999|
|Address Size|**32 bits**|**128 bits**|
|Number of Addresses|**2³² ≈ 4.3 Billion**|**2¹²⁸ ≈ 340 Undecillion**|
|Address Format|Decimal|Hexadecimal|
|Example|192.168.1.10|2001:db8::1|
|Separator|Dot (.)|Colon (:)|
|Header Size|Variable (20–60 bytes)|Fixed (40 bytes)|
|Broadcast|Supported|Not Supported|
|Multicast|Supported|Supported (Preferred)|
|Security|IPSec Optional|IPSec Built-in Support|
|NAT|Commonly Used|Usually Not Required|
|Configuration|Manual / DHCP|SLAAC or DHCPv6|

### Why do we need IPv6 if IPv4 already exists?

IPv4 has a limited address space (about 4.3 billion addresses). As the number of Internet-connected devices grew rapidly, IPv6 was introduced with 128-bit addresses to provide a vastly larger address space and support future Internet growth.


### Which version is used more today?

IPv4 is still the most widely used protocol, but IPv6 adoption is steadily increasing worldwide as ISPs, cloud providers, and organizations transition to support more Internet-connected devices.

## Why didn't they simply create IPv5?

**IPv5 did exist**, but it was **never intended to replace IPv4**.

- It was an **experimental protocol** called the **Internet Stream Protocol (ST)**.
- It was designed for **real-time audio and video streaming**.
- Because version number 5 had already been used, the next Internet Protocol became **IPv6**.


## Will IPv6 ever run out?

 **In theory, yes—any finite number can be exhausted. But in practice, IPv6 provides such an enormous address space (2¹²⁸ addresses) that it is expected to be sufficient for the foreseeable future. If humanity ever reaches that limit, networking standards would evolve and a new addressing protocol would likely be developed.**
