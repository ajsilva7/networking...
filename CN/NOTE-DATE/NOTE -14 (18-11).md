## ARP
- It is used to find the **MAC address** for a **known IP address**

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120115610.png)

- ARP used to identify destination device MAC address based on destination destination device IP address within LAN
- request is broadcast but reply is unicast
- if device is not within LAN it sends default gateway IP address 

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120115620.png)

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120115627.png)

- used to find MAC address domain

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120115634.png)

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120115642.png)

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120115650.png)

- if PCA wants MAC address of destination device and IP address is known 
- it performs ARP request (broadcast)
- switch receive that ARP request and transmit that request to all ports except incoming port 
- PCB says that is my IP address and here this MAC address remaining devices ignore that request because that IP address not theirs 
- then PCB sends reply (unicast) here this is my MAC address
- switch transmit to PCA a stores that PCB MAC address in ARP table (you can check in windows by using command *arp -a*)

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120115657.png)

- i told before the command is *arp -a*
- to delete the ARP table use *arp -d*

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120115705.png)
