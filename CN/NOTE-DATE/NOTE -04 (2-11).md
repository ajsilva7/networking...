### Public IP Address

A public IP address is a globally unique IP address assigned by an Internet Service Provider (ISP). It is used to communicate over the Internet.

### Private IP Address

A private IP address is used within a local network (LAN). It cannot be accessed directly from the Internet.

- **Same private IP in different networks** → ✅ OK
- **Same private IP in the same network** → ❌ conflict
