# IP Routing 

- Routing is the process of selecting best path for Ip packet to forward source to destination across one network to another 
- router the one forwards Ip packets based on routing table

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120120251.png)

- if the PCA wants to send data to a PCB 
- first PCA checks is this destination device (PCB) is within the same network or not 
- if same network it sends data directly to the PCB
- otherwise it sends that data default gateway by using ARP protocol (you may have a doubt how the PCA knows the IP address of default gateway? the answer is you or DHCP)
- R1 receive that IP packet and checks its routing table if it is found it sends that packet directly to PCB
- otherwise R1 performs ARP protocol 
- then PCB receives the packet 

## Gateway 

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120120259.png)

- A gateway is the router interface that connects your LAN to other networks or internet 
- if destination IP  is within network device sends packet directly. no need of gateway
- if destination IP is different network device sends packet to default gateway

## LAB

![](../TRASH/ATTACH/IMAGES/Pasted%20image%2020261120120421.png)

- One router and two networks you can see i configured
- i connected all devices together 
- router i configured by using these commands 
1. Router>enable
2. Router#config t
3. Router(config)#int fa0/0 
4. Router(config-if)#ip address 192.168.1.254 255.255.255.0 
5. Router(config-if)#no shut
6. Router(config-if)#exit
7. Router(config)#
8. Router(config)#int fa0/1
9. Router(config-if)#ip address 192.168.0.254 255.255.255.0
10. Router(config-if)#no shut
11. Router(config-if)#exit
12. Router(config)#
13. Router(config)#exit
14. Router#wr
15. Building configuration...[OK]
16. Router# show ip route

- this are commands i used to configure default gateway
- and i also used DHCP protocol to assign IP address along with subnet mask default gateway  and DNS 
- finally pinged PC 1 to PC 3 in different network
